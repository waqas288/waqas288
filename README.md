# Mohammad Waqas

Biotechnology & Bioinformatics. I turn genomic and clinical data into publishable results.

I work as a freelance bioinformatician (Top Rated on Upwork), with research in blood aging, QTL mapping and colocalization, and CRISPR screen analysis. My first-author preprint on multi-omic blood aging is on bioRxiv.

**Areas:** QTL mapping and colocalization · CRISPR screens · bulk and single-cell RNA-seq · mixed-effects and survival models · machine learning for biology

**Tools:** R · Python · Scanpy · MAGeCK · lme4 · tidyverse · scikit-learn
